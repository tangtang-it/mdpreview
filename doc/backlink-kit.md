## 一、 标准多平台文案库 (Copywriting Materials)

### 1. 极短标语 (Tagline / One-Liner, < 60 字符)
```text
Instant, beautiful Markdown viewer & live editor in your browser.
```

### 2. 中篇短描述 (Short Description, 约 50-80 词，适用于大多数导航站如 Toolify, 1000.tools, AlternativeTo)
```text
MDPreview is a modern, zero-latency, client-side Markdown live previewer and real-time editor built for developers, technical writers, and AI prompt creators. Supporting GitHub Flavored Markdown (GFM), math equations, syntax highlighting across 180+ languages, and one-click HTML/MD export, all parsing happens 100% inside your browser memory with absolute privacy.
```

### 3. 长篇详细描述 (Full Description, 适用于 Product Hunt, Indie Hackers, GitHub README)
```text
In the era of LLMs (ChatGPT, Claude, DeepSeek) where Markdown is the universal standard for technical communication, reading and validating .md documents shouldn't require installing heavy local IDEs or uploading sensitive corporate data to cluttered converter websites.

MDPreview (https://mdpreview.dev) provides a clean, instant, distraction-free environment:
- ⚡ 100% Client-Side & Zero Server Uploads: All Markdown parsing runs in local RAM. Zero cloud storage or tracking.
- 🎨 Full GitHub Flavored Markdown (GFM): Native support for responsive tables, interactive task checklists, strikethroughs, and footnotes.
- 💻 Code Highlighting: Automatic language detection and copy-to-clipboard buttons across 180+ languages.
- 🌓 4 Ergonomic Reading Themes: Switch seamlessly between GitHub Light, GitHub Dark, Eye-Care Warm Sepia, and Midnight Dark.
- 📤 Multi-Format Export: Export standalone styled HTML files or download .md with one click.
- 🌍 Global Multilingual Architecture: Dedicated subdirectories for English, Spanish (/es/), and Portuguese (/pt/).
```

### 4. 核心特性提炼 (Key Features, 列表式)
```text
1. 100% Client-Side Privacy: Your documents never leave your browser.
2. Zero-Lag Synchronized Scrolling: Proportional bidirectional sync between editor and preview.
3. GitHub Flavored Markdown (GFM): Tables, checklists, code blocks, and math formulas.
4. Distraction-Free Workspace: No intrusive bottom banners or floating ads blocking text.
5. Interactive Syntax Cheat Sheet: Built-in quick reference guide with one-click copyable snippets.
6. Offline Ready: Runs entirely in browser cache with responsive mobile support.
```
